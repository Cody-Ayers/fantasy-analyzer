Connect the refresh button

The button asks GitHub to pull fresh ESPN data, which takes about a minute. It needs a GitHub token that's only allowed to run this one workflow. You set it up once per device.

  1. Open GitHub's new token page.
  2. Name it Lineup Lab refresh. Under Repository access, pick Only select repositories and choose this repo.
  3. Under Permissions → Repository permissions, set Actions to Read and write. Leave everything else alone.
  4. Click Generate token, copy it, and paste it here.

It's saved only in this browser and only sent to GitHub. Anyone using this device could use it, so skip this on a shared computer.
